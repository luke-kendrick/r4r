Introduction

Workshop Aims:

  • Provide an introduction to R and RStudio in preparation for PS2010 Psychological Research Methods.

  • Help with navigation in RStudio.

  • Provide an opportunity to practice using code.

About this Session

  • The first hour will involve guided instruction on screen to help you (re)learn the basics of R and RStudio.

  • Raise your hand at anytime if you need help, have a question, or get stuck.

  • We are not able to offer technical support with R/RStudio on your personal device. For today, please use the campus PCs.

  • The second hour will includes an activity for you to practice using basic R functions to learn about a data set.
